# Praca Inżynierska
Głównym założeniem pracy jest stworzenie aplikacji webowej pozwalającej użytkownikom na przeglądanie, ocenianie i odkrywanie filmów dostosowanych do ich indywidualnych gustów.

System oferuje również możliwość dodawania recenzji oraz przeglądania opinii innych użytkowników. Dosepne są również listy w których mozna dodwać listy: do obejrzenia oraz ulubione filmy.

Baza danych filmów jest oparta na publicznym API serwisu TMDB. Dostarcza ono bogaty i stale aktualizowany zbiór informacji o produkcjach filmowych, w tym o najnowszych premiarach kinowych na świecie, zapewniając codzienne odświeżanie danych.
